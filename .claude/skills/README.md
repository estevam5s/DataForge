# Skills

## `criar-linguagem`

Cria uma linguagem de programação completa — ou um banco de dados, um
framework, um runtime, uma DSL. A linguagem-mãe pode ser qualquer uma
(Python, TypeScript, Go, Rust, C, C++, C#, Java).

A skill começa perguntando **para que serve** a linguagem, porque a
resposta muda tudo o que vem depois: uma linguagem de ensino e uma de
telemetria não compartilham quase nada.

O conteúdo veio de construir o DataForge até o fim — inclusive os sete
erros que custaram caro, todos reais e todos documentados lá.

### Usar em qualquer projeto

```bash
cp -r .claude/skills/criar-linguagem ~/.claude/skills/
```

Depois é só pedir: *"crie uma linguagem para …"*, e o Claude Code carrega
a skill sozinho.

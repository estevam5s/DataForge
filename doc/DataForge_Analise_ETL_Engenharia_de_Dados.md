## 30. Recursos que podem fazer parte da sintaxe do DataForge

### Leitura

```text
dados = data.ler.csv("clientes.csv")
dados = data.ler.json("clientes.json")
dados = data.ler.parquet("clientes.parquet")
```

### Transformação

```text
dados
    |> limpar.nulos()
    |> limpar.duplicados()
    |> transformar.normalizar()
    |> transformar.coluna("idade")
    |> filtrar(idade > 18)
```

### Agrupamento

```text
resultado = dados
    |> agrupar.por("cidade")
    |> agregar.media("salario")
    |> agregar.contagem()
```

### ETL

```text
pipeline clientes {

    extrair csv("clientes.csv")

    transformar {
        remover.duplicados()
        preencher.nulos()
        normalizar()
        validar()
    }

    carregar postgres("clientes")
}
```

### Análise

```text
analise vendas {

    dados = ler.parquet("vendas.parquet")

    resumo = dados
        |> agrupar.por("produto")
        |> agregar.soma("valor")
        |> ordenar.desc("valor")

    visualizar.barras(resumo)
}
```

## 32. Objetivo do ecossistema

O ecossistema de dados do DataForge pode abranger todo o ciclo de vida dos dados:

**Ingestão → Extração → Limpeza → Transformação → Validação → Integração → Armazenamento → Processamento → Análise → Visualização → Machine Learning → IA → Monitoramento → Governança.**

A proposta é permitir que projetos pequenos e grandes possam trabalhar com dados utilizando uma sintaxe nativa do DataForge, mantendo uma experiência consistente entre análise de dados, ETL, engenharia de dados, Big Data, BI, Machine Learning e Inteligência Artificial.
